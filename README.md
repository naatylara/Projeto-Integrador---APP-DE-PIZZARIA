# Pizzaria Bella — Projeto Integrador (Desenvolvimento Móvel)

Protótipo acadêmico desenvolvido na Universidade Positivo, 2º semestre de 2026.
Tema: *Violência contra a Mulher — App de Apoio Camuflado*.

> ⚠️ Este é um protótipo acadêmico. **NÃO substitui** atendimento policial,
> jurídico, psicológico ou de saúde. Todos os dados de teste são **fictícios**.

## Canais de ajuda

| Ligue 180 | **180** | Central de Atendimento à Mulher — 24h |
| Polícia Militar | **190** | Emergências |

## Sobre o projeto

O aplicativo se apresenta como um app comum de pedidos de pizzaria. Um item do
cardápio funciona como atalho oculto que leva a uma área de apoio protegida por
PIN, com canais oficiais de ajuda, alerta de emergência (SOS) e uma rede de
contatos de confiança. Uma função de **saída rápida** volta imediatamente à
fachada.

## Tecnologias

- **Mobile:** React Native + Expo
- **API:** Node.js + Express
- **Banco de dados:** PostgreSQL

## Funcionalidades (planejadas)

- [ ] Fachada: cardápio e carrinho de pizzaria
- [ ] Acesso à área de apoio via atalho oculto + PIN
- [ ] Tela de apoio com Ligue 180 e 190
- [ ] CRUD de Rede de Apoio (contatos de confiança e prioridade)
- [ ] SOS: avisa o contato prioritário e abre o discador do 190
- [ ] Saída rápida
