## Observações

- Por ser um projeto individual, todas as etapas (planejamento, protótipo,
  desenvolvimento do app e da API, modelagem de dados, documentação e testes)
  ficam sob responsabilidade da aluna.
- Por não cursar Data Science neste semestre, a aluna é avaliada somente pelos
  critérios de Desenvolvimento Móvel. A tela de Autoavaliação de Risco, se
  implementada, usará um valor simulado.
- O CRUD sob responsabilidade da aluna é o de Rede de Apoio, com cadastro, consulta, edição e exclusão de contatos.
- A API foi desenvolvida com Node.js e Express, utilizando arquivos JSON para armazenamento dos dados.
- O projeto também possui integração de alertas SOS com a API e um painel web de monitoramento, com consulta e atualização do status dos alertas.
- Os dados utilizados nos testes são fictícios, e os alertas SOS não realizam acionamento policial automático.
